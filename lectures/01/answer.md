## 宿題

- 取り組んだレベル：実装
- やったこと：
  - `app/ask.py` に `--chat` を追加した。同じ `client.chats.create(model=MODEL)` のセッションで `send_message` を繰り返し、ユーザーの質問とモデルの回答を次のリクエストに含める。
  - 従来の1回だけの質問と、質問省略時の講座固有の質問は維持した。会話モードでも各リクエストの入力・出力トークン数を表示する。
  - 空行は送信せず、`/exit`、`/quit`、入力時のCtrl+D・Ctrl+Cで終了できる。履歴は実行中だけ保持し、終了後の再開やファイル保存には対応していない。
- 結果：
  - 動作確認用の架空の設定として「私の好きな色は青です。覚えておいてください。返事は短くしてください。」と送ったところ、「承知しました。青色ですね。覚えました！」と返った（入力18 / 出力11）。
  - 続けて「私の好きな色は何ですか？」と送ると「青です！」と返った（入力37 / 出力3）。2回目には色を再指定していないため、前の会話が使われたことを確認できた。
  - 追加の手動確認では、最初の質問を引数に渡して合言葉「青い灯台」を伝えた（入力25 / 出力13）。対話入力で「さっきの合言葉は何でしたか？合言葉だけ答えてください。」と尋ねると「青い灯台」と返った（入力56 / 出力4）。空行は送信されず、`/exit` と `/quit` で正常終了することも確認した。
- 気づき・疑問：
  - 会話履歴を送ることで、省略した情報を前の発言から補って回答できる。一方、用語集を渡しているわけではないため、講座固有の知識が自動で正しくなるわけではない。
  - 入力トークン数は今の質問だけでなく過去の会話も含む。今回も2回目は37トークンとなり、会話が長くなるほど無料枠を消費しやすくなると考えられる。

### 実行方法

```bash
# 通常の1回質問
uv run --env-file .env python -m app.ask "LoRAとは何ですか？"

# 会話モード（起動後に質問を入力）
uv run --env-file .env python -m app.ask --chat

# 最初の質問を引数で渡して続けることもできる
uv run --env-file .env python -m app.ask --chat "LoRAとは何ですか？"
```

会話モードで「確認用の合言葉は『青い灯台』です。覚えてください。」、続いて「さっきの合言葉は何でしたか？」と入力し、前の発言が引き継がれることを確認できる。終了は `/exit` または `/quit`。
